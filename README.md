# Comparador de Seguros Médicos

Página estática (un solo `index.html`) para comparar planes de seguro médico lado a lado.

- Empieza con 1 plan; el botón **+** agrega otro, en blanco o copiando los datos de un plan anterior.
- Compara pago mensual, deducible, out-of-pocket, visitas al médico/especialista, medicamentos, laboratorios, hospital, salud mental y embarazo.
- Resalta en verde el mejor valor y en rojo el peor de cada fila; calcula la prima anual y el peor caso anual (prima + out-of-pocket).
- Los datos se guardan en el navegador (localStorage). Se pueden exportar/importar como JSON e imprimir a PDF.

Publicado con GitHub Pages desde la rama `main` (raíz).
